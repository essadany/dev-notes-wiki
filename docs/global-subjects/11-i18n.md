# 11. Internationalisation (i18n)

> 🎯 **Résumé.** Une interface traduite ne se limite pas à remplacer des mots : grammaire, pluriels, dates et devises changent avec la locale. On centralise les chaînes dans la librairie i18n de la stack et on délègue le formatage à l'API native `Intl`. Le piège principal est de concaténer des traductions ou d'ignorer les différences de longueur (l'allemand déborde), ce qui casse à la fois le sens et la mise en page.

---

## 🧭 1. Contexte

| Stack | Solution |
|---|---|
| React | react-i18next, FormatJS (react-intl) |
| Vue | vue-i18n |
| Angular | `@angular/localize` (traduction au build), Transloco, ngx-translate (runtime) |
| Svelte | svelte-i18n, Paraglide |

Utiliser l'API native `Intl` pour dates, nombres, devises. **Pièges** : concaténer des chaînes traduites (la grammaire change selon la langue) ; pluriels ; texte qui déborde (l'allemand est plus long).

---

## 💻 2. Exemples techniques

Configuration react-i18next avec interpolation et pluriels (`_one` / `_other`, les règles `Intl` d'i18next v21+) consommée via `useTranslation` :

```tsx
// i18n.ts
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';

i18n.use(initReactI18next).init({
  lng: 'fr',
  fallbackLng: 'en',
  resources: {
    fr: {
      translation: {
        hello: 'Bonjour {{name}}',
        inbox_one: '{{count}} message',
        inbox_other: '{{count}} messages',
      },
    },
    en: {
      translation: {
        hello: 'Hello {{name}}',
        inbox_one: '{{count}} message',
        inbox_other: '{{count}} messages',
      },
    },
  },
});

export default i18n;

// InboxHeader.tsx
import './i18n';
import { useTranslation } from 'react-i18next';

export function InboxHeader({ name, count }: { name: string; count: number }) {
  const { t } = useTranslation();

  return (
    <h1>
      {t('hello', { name })} — {t('inbox', { count })}
    </h1>
  );
}
```

Côté Vue, `createI18n` en mode Composition API avec le même principe de phrases complètes (jamais de concaténation) :

```ts
import { createI18n } from 'vue-i18n';

export const i18n = createI18n({
  legacy: false,
  locale: 'fr',
  fallbackLocale: 'en',
  messages: {
    fr: {
      hello: 'Bonjour {name}',
      inbox: '{count} message | {count} messages',
    },
    en: {
      hello: 'Hello {name}',
      inbox: '{count} message | {count} messages',
    },
  },
});
```

Formatage natif des dates, nombres et devises, partageable entre Angular, Svelte ou un simple utilitaire TypeScript — la locale est celle de l'utilisateur, pas celle du serveur :

```ts
export function formatInvoice(locale: string, amount: number, date: Date) {
  const formattedAmount = new Intl.NumberFormat(locale, {
    style: 'currency',
    currency: 'EUR',
  }).format(amount);

  const formattedDate = new Intl.DateTimeFormat(locale, {
    dateStyle: 'long',
    timeStyle: 'short',
  }).format(date);

  return `${formattedAmount} — ${formattedDate}`;
}

formatInvoice('fr-FR', 1234.5, new Date('2026-11-18T14:30:00Z'));
```
